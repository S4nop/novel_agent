# 프롬프트 편집 가이드 (Prompt editing guide)

이 폴더의 `.md` 파일이 에이전트가 모델에게 보내는 **실제 지시문**입니다.
파이썬을 몰라도 이 파일들만 고치면 작품의 성격을 바꿀 수 있습니다.

## 규칙 3개

1. **`${이름}` 은 자리표시자입니다. 지우지 마세요.**
   실행할 때 실제 값(아이디어, 장르, 원고 등)으로 치환됩니다.
   지우면 그 정보가 모델에 전달되지 않고, 저장할 때 오류로 막힙니다.
2. 그 외 문장은 자유롭게 고치세요. 한국어로 쓰면 됩니다.
3. 저장 후에는 **서버를 재시작하거나** 웹 콘솔의 `프롬프트` 패널에서 저장하세요
   (콘솔에서 저장하면 즉시 반영되고, 자리표시자 검사도 자동으로 해 줍니다).

## 어떤 파일이 무엇을 바꾸나

| 파일 | 언제 쓰이나 | 고치면 달라지는 것 |
|---|---|---|
| `drafter_system.md` | 매 화 집필 | 원고의 문체·시점·분량·금지사항 |
| `style_rules.md` | 매 화 집필(위 파일에 삽입) | 유치함 방지 규칙 전체. **가장 영향이 큽니다** |
| `analyst_system.md` | 기획 단계 전반 | 기획자 역할의 기본 태도 |
| `restraint.md` | 전제·캐논 생성 | 설정 과잉/억지 조어 억제 강도 |
| `genre_inference.md` | 1단계 | 아이디어에서 장르를 읽어내는 방식 |
| `northstar.md` | 2단계 | 전제 후보 3개를 뽑는 방향 |
| `canon_init.md` | 3단계 | 인물·세계관·용어집·보이스 바이블 |
| `episode_plan.md` | 4단계 | 비트시트(훅·전개·절단) 설계 |
| `interview_system.md` / `interview_request.md` | 인터뷰 | 작가에게 무엇을 물을지 |
| `voice_spec_guidance.md` | 캐논 생성 | 보이스 바이블 작성 지침 |
| `revise_instruction.md` | 수정 루프 | 지적사항을 어떻게 고치라고 지시할지 |

## 안전하게 실험하는 법

- 폴더째 복사해 두고 `NOVEL_PROMPTS_DIR=/path/to/copy` 로 실행하면
  원본을 건드리지 않고 A/B 비교할 수 있습니다.
- 원고 품질은 웹 콘솔의 **문체 린트**(무료, 토큰 0)로 즉시 점수 비교가 됩니다.
- 되돌리려면 git 으로 이 폴더만 복원하세요: `git checkout prompts/`
